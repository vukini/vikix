# Website refresh — 2026-10-21

The homepage introduces Vikix through its value to an independent developer:
build more, understand more, and become more self-sufficient. The Office
example is explicitly illustrative. Real desktop captures are labelled as
an earlier version, and the cloud direction is labelled in development.
Technical foundations remain on site/void.html and in the guides.

The entire site before this refresh is preserved in the local Git branch
`website-before-refresh`, at commit `244c133`. To restore the original site
in a future desk, restore `site/` from that branch (or commit) and remove the
new `site/refresh.css`, `site/site.js` and `site/wallpapers/` files. Review
and commit the restoration through the normal desk workflow. No release,
merge or push is part of this refresh task.
