# Website wallpaper selection

These WebP copies come from the Vikix wallpaper collection at
https://github.com/vukini/wallpapers (the installed collection on 2026-10-21).
The original basenames are retained. Images are at most 1600 pixels wide,
encoded at WebP quality 82. They are shown as wallpapers, not desktop screenshots.

The gallery links to the source collection. The site does not change or
replace the desktop's original images.
