# hello (Go)

The smallest Go program: `go.mod` names the module, `main.go` is the code.

    make run        # or: go run .

Try: `gofmt -d main.go` shows how Go wants it formatted; `go vet .`
looks for mistakes; `go mod init other` starts a module of your own.
Docs: `go doc fmt.Println`; Zeal's Go docset.
