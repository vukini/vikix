# Go

A small, plain language for programs that do many things at once:
servers, command-line tools. Fast to compile, one way to format, and a
large standard library.

## On this machine

<!-- tools -->

- Offline docs: `go doc` (any package: `go doc strings.Split`), Zeal's Go docset
- Examples: `~/dev/go/examples/` (`make run`, or `go run .`, in each)

## Where to start

1. A Tour of Go (below), in the browser, start to finish.
2. `examples/hello`, then `go mod init mine` in a folder of your own.
3. Go by Example when you need to see how something is done.
4. `examples/workers` for goroutines; then Learn Go with Tests.
