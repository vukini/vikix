# hello (Haskell)

The smallest Haskell program, as a cabal project: `hello.cabal` says what
to build, `Main.hs` is the code.

    make run        # or: cabal run hello

Try: `ghci Main.hs`, then type `main`, or `map (*2) [1..5]`; `:t putStrLn`
shows a type. `cabal init` starts a project of your own.
Docs: `~/dev/haskell/docs/ghc/`; Zeal's Haskell docset.
