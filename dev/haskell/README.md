# Haskell

A purely functional language: functions without side effects, strong
types worked out for you, and lazy evaluation. It changes how you think
about programs, whatever language you write in afterwards.

## On this machine

<!-- tools -->

- Offline docs: `~/dev/haskell/docs/ghc/` (the GHC user's guide and base library); Zeal's Haskell docset
- Examples: `~/dev/haskell/examples/` (`make run`, or `cabal run`, in each)

## Where to start

1. `ghci`, and the first chapters of Learn You a Haskell, trying everything at the prompt.
2. `examples/wordfreq` and `examples/lazy`, loaded in ghci (`ghci Main.hs`).
3. The Haskell MOOC from the University of Helsinki, with its exercises.
4. Hoogle, whenever you wonder whether a function exists: search by its type.
