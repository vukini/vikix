# PicoLisp

A tiny, fast Lisp interpreter with a database, a Prolog, and a web GUI
built in. Everything is a cell, a number or a symbol; no compiler, and
none needed.

## On this machine

<!-- tools -->

- Vikix builds PicoLisp from the current release (65-languages) into `~/.local/opt/picolisp`
- Examples: `~/dev/picolisp/examples/` (`make run` in each)

## Where to start

1. The tutorial, with `pil +` open beside it.
2. `examples/wordfreq`, then `examples/database`.
3. The reference, for each function as you meet it.
4. PicoLisp's solutions on Rosetta Code, to see idiomatic code for familiar problems.
