# Free Pascal and Lazarus

Pascal was made for teaching: clear, strict, readable. Free Pascal is the
modern compiler; Lazarus is its IDE, for native desktop programs with a
form designer.

## On this machine

<!-- tools -->

- Lazarus: `vikix-lazarus`, or Lazarus in the launcher (Super+d); the first start asks you to click Start IDE once
- Offline docs: `man fpc`; in the Lazarus IDE, F1 on any word
- Examples: `~/dev/pascal/examples/` (`make run` in each; `make ide` opens the Lazarus one)

## Where to start

1. `examples/hello` and `examples/wordfreq`: plain Pascal, compiled by `fpc`.
2. Modern Object Pascal Introduction (below): the language as Free Pascal has it now.
3. `examples/clicker`, then the Lazarus tutorial on the wiki: a program with windows.
