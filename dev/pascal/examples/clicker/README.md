# clicker (Free Pascal, Lazarus)

What Lazarus is known for: native desktop programs from Pascal. A window
with a button that counts its clicks, written with the LCL, all in code.

    make run        # build with lazbuild, then open the window
    make ide        # the same project in the Lazarus IDE (F9 runs it)

Try: add a Reset button; open it in the IDE and add a form with the
designer (File, New Form) to see the .lfm file it writes for you.
Docs: in the IDE, F1 on any word; https://wiki.lazarus.freepascal.org
