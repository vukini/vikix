# hello (Java)

The smallest Java program, as a Gradle project: `build.gradle` says what
to build, the code is in `src/main/java/`.

    make run        # or: gradle run

Try: `jshell` for a prompt where each line of Java runs at once; `java
src/main/java/Hello.java` runs one file with no build at all.
Docs: Zeal's Java docset; https://dev.java/learn/
