# hello (Ruby)

The smallest Ruby program. There is nothing to build: `make` only checks
the syntax.

    make run        # or: ruby hello.rb

Try: `irb` for a prompt: `3.times { puts "hi" }`, `[3, 1, 2].sort.reverse`,
`"ruby".methods.grep(/case/)` (everything is an object you can ask).
Docs: `ri String#upcase` (ruby-ri); Zeal's Ruby docset.
