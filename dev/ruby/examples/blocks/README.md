# blocks (Ruby)

What Ruby is known for: code that reads like prose. Blocks passed to
methods (`select`, `map`, and a `timed` method of our own with `yield`),
and a class whose methods are written by the program itself with
`define_method`.

    make run

Try: add `"blue"` to the colours and call `light.blue!`; write a method
that runs its block three times; `ri Enumerable#each_slice`.
Docs: `ri Enumerable`; the Ruby docs on blocks (see ~/dev/ruby/README.md).
