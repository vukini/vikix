# Ruby

A language made for programmer happiness: code that reads almost like
English, everything an object, and blocks everywhere. Known for Rails,
and for scripts that are a pleasure to write.

## On this machine

<!-- tools -->

- Offline docs: `ri` (e.g. `ri Array#map`); Zeal's Ruby docset
- Gems go under your home with `gem install --user-install NAME`, or per project with a Gemfile and `bundle`
- Examples: `~/dev/ruby/examples/` (`make run` in each)

## Where to start

1. Ruby in Twenty Minutes (the quickstart), with `irb` open.
2. `examples/wordfreq` and `examples/blocks`.
3. Ruby Koans: small failing tests that teach the language as you fix them.
4. The official docs and `ri` for every class and method.
