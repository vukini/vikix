# Scheme

Lisp made small: a handful of ideas (functions, recursion, tail calls,
continuations) from which everything else is built. The language of
SICP, the classic book on how programs work.

## On this machine

<!-- tools -->

- The examples are for Chez Scheme (`scheme`); Guile runs most of the same code
- Examples: `~/dev/scheme/examples/` (`make run` in each)

## Where to start

1. Teach Yourself Scheme in Fixnum Days, a short tour, with `scheme` open.
2. `examples/wordfreq` and `examples/callcc`.
3. The Scheme Programming Language (TSPL), by Chez's author, as the reference.
4. SICP, slowly: the book that teaches programming itself, not a language.
