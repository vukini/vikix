# Python

Easy to read and quick to write, with a library for almost anything.
The usual first language, and the usual language for data and science.

## On this machine

<!-- tools -->

- Offline docs: `~/dev/python/docs/` (the tutorial, library and language reference), `pydoc re`, Zeal's Python docset
- JupyterLab: `jlab`, in `~/dev/python`, with numpy, pandas, matplotlib, scipy and sympy
- Examples: `~/dev/python/examples/` (`make run` in each)
- Void's Python won't take `pip install`: make an environment with `uv venv` and install there, or `pipx install` for a program

## Where to start

1. The official tutorial (offline, above) or Python for Everybody, from the start.
2. `examples/wordfreq`: compare it with the C one.
3. Automate the Boring Stuff, to use Python on your own files.
4. Think Python, for how to think about programs.
