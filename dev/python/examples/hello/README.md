# hello (Python)

The smallest Python program. There is nothing to compile: `make` only
checks the syntax, and `make run` runs it.

    make run        # or: python3 hello.py

Try: `python3` (or `ipython`) on its own for a prompt where each line runs
as you type it; `jlab` opens JupyterLab in ~/dev/python.
Docs: `~/dev/python/docs/`, the tutorial first.
