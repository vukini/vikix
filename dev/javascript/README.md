# JavaScript

The language of the web: every browser runs it, and Node runs it
everywhere else, for servers, tools and scripts. Quick to start with,
and the largest package collection there is.

## On this machine

<!-- tools -->

- Offline docs: Zeal's JavaScript docset (the MDN reference)
- Examples: `~/dev/javascript/examples/` (`make run` in each)
- Packages go into each project's own `node_modules` (`npm install NAME`); `npm search NAME` looks for one

## Where to start

1. The Modern JavaScript Tutorial (javascript.info), part 1, with `node` open.
2. `examples/wordfreq`, then `examples/server`: promises and `await`.
3. Eloquent JavaScript, for how to think in it.
4. MDN whenever you need the exact behaviour of something.
