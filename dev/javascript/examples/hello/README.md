# hello (JavaScript)

The smallest JavaScript program, run by Node. There is nothing to build:
`make` only checks the syntax.

    make run        # or: node hello.js

Try: `node` for a prompt: `[1, 2, 3].map(x => x * 2)`, `"abc".toUpperCase()`;
the same line works in Firefox's console (F12), where JavaScript started.
Docs: MDN (see ~/dev/javascript/README.md); Zeal's JavaScript docset.
