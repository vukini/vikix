# Zig

A small, explicit systems language: no hidden memory allocations, no
hidden control flow, and code that runs at compile time (`comptime`).
Its compiler also builds C, and its build system is Zig code.

## On this machine

<!-- tools -->

- Offline docs: the language reference in `~/dev/zig/docs/`; `zig std` opens the standard library's docs in the browser
- Examples: `~/dev/zig/examples/` (`make run`, or `zig build run`, in each)
- The docs and examples here match this Zig (0.13); code written for newer Zig may not build

## Where to start

1. `examples/hello`, then `zig init` in an empty folder.
2. Ziglings (below): small broken programs to fix, one idea each.
3. zig.guide alongside, and the language reference when you want the exact rule.
4. `examples/comptime` with `make check`.
