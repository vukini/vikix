# hello (Zig)

The smallest Zig program. `build.zig` says how to build it; it is Zig
code too.

    make run        # or: zig build run

Try: `zig run src/main.zig` builds and runs a single file with no
build.zig; `zig init` in an empty folder starts a project of your own.
Docs: the language reference in `~/dev/zig/docs/`; `zig std` for the library.
