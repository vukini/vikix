# hello (Rust)

The smallest Rust program, as a cargo project: `Cargo.toml` describes it,
`src/main.rs` is the code.

    make run        # or: cargo run

Try: `cargo build --release` for an optimised build in target/release;
`cargo new other` to start a project of your own the same way.
Docs: `~/dev/rust/docs/rust/book/index.html`, chapter 1.
