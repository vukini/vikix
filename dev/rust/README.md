# Rust

Fast like C, but the compiler checks that memory is used safely, so whole
kinds of bugs can't happen. Strict at first; the error messages teach.

## On this machine

<!-- tools -->

- Offline docs: `~/dev/rust/docs/rust/` — the Rust book (`book/index.html`) and the standard library (`std/index.html`); Zeal's Rust docset
- Examples: `~/dev/rust/examples/` (`make run`, or `cargo run`, in each)

## Where to start

1. `examples/hello`, then `cargo new mine && cd mine && cargo run` for a project of your own.
2. The Rust book, chapters 1 to 9, with Rustlings (below) alongside for practice.
3. `examples/results`: break it and read what the compiler says.
4. Rust by Example when you want to see a feature rather than read about it.

## Online

## Free books and exercises

- The Rust Programming Language ("the book") — https://doc.rust-lang.org/book/ — also offline, above
- Rust by Example — https://doc.rust-lang.org/rust-by-example/
- Rustlings — https://github.com/rust-lang/rustlings — small exercises that don't compile until you fix them
- Comprehensive Rust, Google's course — https://google.github.io/comprehensive-rust/
