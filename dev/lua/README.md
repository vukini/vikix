# Lua

A small, fast language made to live inside other programs: games,
Neovim, window managers, network tools. One data structure (the table),
a tiny core, and metatables to build the rest.

## On this machine

<!-- tools -->

- Offline docs: the 5.4 manual, `~/dev/lua/docs/manual.html`; Zeal's Lua docset
- Neovim's configuration is Lua: `~/.config/nvim` is real Lua to read
- Examples: `~/dev/lua/examples/` (`make run` in each)

## Where to start

1. Learn X in Y minutes, Lua: the whole language on one page.
2. Programming in Lua, by Lua's author: the first edition is free online (it's for Lua 5.0; the ideas all still hold).
3. `examples/wordfreq`, then `examples/metatables`.
4. The reference manual for the details of 5.4.
