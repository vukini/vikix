# hello (SQL)

The smallest SQL, run by SQLite: a SELECT needs no table. There is
nothing to build.

    make run        # or: sqlite3 < hello.sql

Try: `sqlite3` for a prompt (or `litecli`, with completion and colours):
`SELECT 6 * 7;`, `SELECT date('now');`, `.help` for SQLite's own commands.
Docs: `~/dev/sql/docs/` (the SQLite docs, offline); Zeal's SQLite docset.
