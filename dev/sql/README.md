# SQL

The language for asking questions of data in tables, the same in almost
every database. Here with SQLite: a whole database in one file, and the
most widely used database engine there is.

## On this machine

<!-- tools -->

- Offline docs: `~/dev/sql/docs/` (the SQLite docs); Zeal's SQLite docset
- Examples: `~/dev/sql/examples/` (`make run` in each)

## Where to start

1. SQLBolt: short lessons with exercises in the browser.
2. `examples/library`: open `library.db` in `sqlitebrowser` and ask it things.
3. Select Star SQL, a free book built around one real data set.
4. `examples/wordfreq`: SQL doing what you'd think needs a loop.
