# hello (OCaml)

The smallest OCaml program, built by dune: `dune-project` marks the
project, `dune` says what to build, `hello.ml` is the code.

    make run        # or: dune exec ./hello.exe

Try: `ocaml` for a prompt (end each phrase with `;;`): `1 + 2;;`,
`List.map (fun x -> x * 2) [1; 2; 3];;`; `utop` is a nicer one
(`opam install utop`).
Docs: `man ocaml`; https://ocaml.org/docs
