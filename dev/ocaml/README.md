# OCaml

A functional language with a practical side: fast native code, a strong
type system that infers the types for you, and pattern matching the
compiler checks. Used for compilers, proof assistants and trading systems.

## On this machine

<!-- tools -->

- Tools from opam: run `opam init` once (it asks to set up your shell), then `opam install utop ocaml-lsp-server ocamlformat`
- Offline docs: `man ocaml`
- Examples: `~/dev/ocaml/examples/` (`make run`, or `dune exec ./x.exe`, in each)

## Where to start

1. The tutorials on ocaml.org/docs, with `ocaml` (or utop) open beside them.
2. `examples/wordfreq`, then `examples/calc`: add a case and let the compiler guide you.
3. OCaml Programming: Correct + Efficient + Beautiful, Cornell's course book.
4. Real World OCaml, for real programs with libraries.
