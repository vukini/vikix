# Forth

A language with almost no syntax: words separated by spaces, working on a
stack. You build up a vocabulary for your problem, word by word, down to
the machine. Still used in boot loaders, spacecraft and small devices.

## On this machine

<!-- tools -->

- Offline docs: `info gforth` (or in Emacs: C-h i, then Gforth)
- Examples: `~/dev/forth/examples/` (`make run` in each)

## Where to start

1. Easy Forth, a page of small lessons that run in the browser.
2. Starting Forth, the classic introduction, with `gforth` open.
3. `examples/words`, then `examples/wordfreq`: a real program, and how Forth's dictionary serves as a hash table.
4. The Gforth manual for everything gforth adds.
