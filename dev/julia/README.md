# Julia

A language for numbers and science that reads like Python and runs like
C: each function is compiled for the types it is called with, and
multiple dispatch lets packages work together.

## On this machine

<!-- tools -->

- `juliaup` keeps Julia itself (in `~/.julia/juliaup`); `juliaup update` brings a new release
- Packages: in `julia`, press `]` then `add Plots` (they go to `~/.julia`)
- Help: in `julia`, press `?` then a name
- Examples: `~/dev/julia/examples/` (`make run` in each)

## Where to start

1. The "Getting Started" and "Variables" chapters of the manual, with `julia` open.
2. Think Julia, a first programming book in Julia.
3. `examples/dispatch`: add a type and a method.
4. MIT's Computational Thinking course, for Julia in science.
