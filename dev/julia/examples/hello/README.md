# hello (Julia)

The smallest Julia program. There is nothing to build: `make` only checks
that it parses, `make run` runs it.

    make run        # or: julia hello.jl

Try: `julia` for a prompt: `2^10`, `sqrt(2)`, `[1, 2, 3] .* 2`; press `?`
for help on anything, `]` for the package manager.
Docs: https://docs.julialang.org
