# Racket

A Scheme grown into a platform: a huge library, an IDE made for
learning (DrRacket), and tools for making languages of your own, each
file saying which language it is written in (`#lang`).

## On this machine

<!-- tools -->

- Offline docs: `~/dev/racket/docs/racket/` (the whole Racket documentation, from the racket-doc package); Zeal's Racket docset
- Examples: `~/dev/racket/examples/` (`make run` in each)

## Where to start

1. The Quick introduction ("An Introduction to Racket with Pictures") in DrRacket.
2. How to Design Programs (HtDP): a whole first course, in teaching languages DrRacket has built in.
3. `examples/wordfreq` and `examples/pictures`.
4. Beautiful Racket, when you want to make a language of your own.
