# pictures (Racket)

What Racket is known for: teaching, and a library for everything. A
Sierpinski triangle, drawn by a function that calls itself: three smaller
triangles make each bigger one. `make run` saves it as triangle.png;
`make view` opens it too.

    make view

Try: open it in DrRacket, run it, and type `(sierpinski 3)` at the
prompt: the picture appears right there; change the colour, or use
`(disk 6)` in place of the square.
Docs: the pict library in the offline docs (~/dev/racket/docs), "Pict: Functional Pictures".
