# hello (Racket)

The smallest Racket program. `#lang racket/base` names the language the
file is in; `make` compiles it with raco, `make run` runs it.

    make run        # or: racket hello.rkt

Try: `drracket hello.rkt` opens it in DrRacket, the IDE made for
learning; `racket` for a prompt: `(+ 1 2)`, `(string-upcase "hi")`.
Docs: `~/dev/racket/docs/racket/` (the Racket guide and reference, offline).
