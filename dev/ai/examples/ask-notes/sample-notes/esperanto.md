# Esperanto

## The accusative

The object of a verb takes -n: *Mi vidas la hundon* (I see the dog).
Because of it the word order is free: *La hundon mi vidas* means the same.

## Correlatives

A table of 45 words from five beginnings and nine endings: ki- (which),
ti- (that), i- (some), ĉi- (every), neni- (no); -o thing, -u person,
-e place, -am time. So *kiam* is when, *tie* is there, *neniu* is nobody.
