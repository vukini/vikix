# Kiel navigi en Vikix

Ĉi tiuj paĝoj estas por iu, kiu instalis Vikix kaj volas scii, kie ĉio troviĝas kaj kiel personigi ĝin; la unuaj du estas por atingi ĉi tiun celon, de malplena komputilo ĝis la unua horo sur la labortablo. La ĉefa [LEGMI.MD](../../README.md) estas la kompleta referenco: ĉiu klavo, ĉiu listo de pakaĵoj, ĉiu testo. Ĉi tiuj paĝoj estas la mapo.

La gvidiloj estas sur via komputilo en tri formoj: kiel ĉi tiuj dosieroj,
kiel HTML-paĝoj kun diagramoj prezentitaj kiel bildoj, kaj kiel Info-manlibro.
La angla eldono restas la defaŭlta; la Esperanto-eldono havas propran eniron.

La Esperanto-gvidilo estas en `~/vikix/docs/eo/`. En `Super+m` → Help,
elektu *Vikix guide: Esperanto (Emacs or terminal)* aŭ *Vikix guide: Esperanto
in the browser*. En Emacs, premu `C-h i` kaj elektu **Vikix Esperanto**, aŭ
uzu `M-x info RET (vikix-eo) RET`; en terminalo, `info vikix-eo`.
La HTML-paĝoj havas ligilojn por elekti inter English kaj Esperanto.
La reta versio estas ĉe [vikix.dev/guide/eo/](https://vikix.dev/guide/eo/).
La komandreferenco restas en la angla kaj estas generata el la programoj.
Ĉi tiu traduko estis farita per loka AI; la angla gvidilo estas la referenco
se klarigo mankas aŭ malsamas.

Ĉiu komando `vikix` ankaŭ havas manpaĝon, kaj do ankaŭ ĉiu komando de aldonaĵo, kiun vi aldonis: `man vikix` listigas ilin, `man vikix-backup` aŭ `man inbox` estas la tutaĵo de unu, kaj `man -k vikix` trovas paĝon per vorto. La paĝo *La komandoj*, en la tabelo sube, estas la sama en unu loko. Ili diras, kion ĉiu komando diras per sia `-h`, ĉar ambaŭ estas kreitaj el la samaj linioj.

## Ses aferoj, kiujn vi devas scii unue

1. **Vikix staras sur Void.** Sub ĝi estas ordinara Void Linux: xbps por pakaĵoj, runit por servoj, neniu systemd. Vikix aldonas labortablon (StumpWM), aro da programoj, ilia agordo kaj la komandon `vikix`. Ĝi ne anstataŭigas ion de Void.
2. **La instalado estas la bazo; la reston vi aldonas.** La bazo estas kompleta labortablo: terminalo, navigilo, dosieroj, sono, Wi-Fi, Bluetooth, la AI-agento. Lingvoj, redaktiloj, LibreOffice, presado, Windows kaj lokala AI estas **funkcioj**: `vikix features` listigas ilin, `vikix add NAME` instalas unu, `vikix remove NAME` forigas ĝin denove, kaj `vikix update` konservas tion, kion vi elektis.
3. **Ĉiu agorddosiero estas aŭ de Vikix aŭ via.** La dosieroj de Vikix estas simbolaj ligoj en `~/vikix`, kaj `vikix update` anstataŭigas ilin. Viaj dosieroj estas kopioj, kiujn Vikix faris unufoje kaj neniam tuŝas denove. Ŝanĝu viajn dosierojn, ne tiujn de Vikix. [Kie ĉio troviĝas](map.md) diras, kiu estas kio.
4. **`~/.stumpwm.d/user.lisp` estas, kie la labortablo estas via.** Ĝi ŝarĝiĝas laste, do ĉio en ĝi venkas super la agordoj de Vikix: klavoj, programoj startiĝantaj, la terminalo, la menuo, la breto.
5. **Viaj dosieroj havas funkcion "malfari".** `vikix snapshot` antaŭ ŝanĝo, `vikix changes` post ĝi, `vikix undo` por retiri ĝin.
6. **`Super+m`, `Super+/` kaj `Super+F1` estas la vojo enen.** La bonveniga ekrano, kiu malfermiĝis ĉe via unua ensaluto, ankaŭ estas tie (`Super+m` → *Bonvenon*), kaj ankaŭ *Aldoni programaron* por la lingvoj, redaktiloj kaj la resto. `Super+m` estas la menuo de Vikix, en sekcioj (Fenestroj, Sistemo, Aplikoj...): Enter malfermas unu, kaj tajpante vorton trovas eniraĵon de ĉiu el ili, do kie ĉi tiuj gvidiloj diras `Super+m` → *Io*, tajpante vorton de ĝi vi atingas ĝin (eniraĵo por funkcio, kiun vi ne havas, estas forlasita ĝis vi aldonas ĝin); `Super+/` montras ĉiun klavon je unu vido, kaj `Super+F1` listigas ilin, por ke vi povu serĉi kaj funkcii unu el tie. `vikix doctor` kontrolas, ke ĉio estas sur sia loko.
